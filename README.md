# Quantitative Financial Risk Engine: Value at Risk (VaR) Analysis

This repository contains the files and codebase for a group project in **DSC003 (Part A) — Probability and Statistics**. 

The project implements a **Quantitative Financial Risk Engine** with both a command-line script and a real-time web dashboard. It applies continuous Cumulative Distribution Function (CDF) and Quantile Function theory to asset returns to calculate Value at Risk (VaR) and evaluate parametric distribution fits.

## Installation & Running the Dashboard

### Prerequisites
Make sure Python 3 is installed along with the required libraries:
```bash
pip install yfinance numpy pandas scipy matplotlib streamlit
```

### Running the Web Dashboard (Frontend)
To launch the real-time interactive web dashboard, run the following command in your terminal:
```bash
streamlit run app.py
```
This will start a local server and automatically open the dashboard in your web browser (typically at `http://localhost:8501`).

### Running the Command-Line Engine (CLI)
To run the static calculations and save the default S&P 500 reports/plots to disk:
```bash
python risk_engine.py
```
